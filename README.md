# ગુજરાતી ધોરણ ૧ - પાઠ્યપુસ્તક & ડિજિટલ સ્વાધ્યાય પોથી

std 1 gujrati 1 to 4 lesson - Interactive digital textbook and practice workbook for Gujarati Standard 1.

## 📚 એકમ યાદી (Lessons Covered)
- **એકમ ૧:** અજબ જેવી વાત છે
- **એકમ ૨:** વરસાદની મજા
- **એકમ ૩:** કાબર કલાકો અને કબૂતર
- **એકમ ૪:** ઘર અને ગુફા

## 🚀 How to Run Locally
Double-click `run_index.bat` or launch `server.py` using Python:
```bash
python server.py
```
Or simply open `index.html` directly in any web browser.
